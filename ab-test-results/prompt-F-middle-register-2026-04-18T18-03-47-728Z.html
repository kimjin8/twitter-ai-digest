🚀 TOOLS & PRODUCTS

Anthropic released Claude Opus 4.7 and Claude Design to target professional workflows.

The new model shows measurable gains in economically important tasks over version 4.6. Claude Design allows users to generate high-quality UI directly. This move caused Figma's market value to drop by 7%.

via Jeremy Howard, Ethan Mollick, Charly Wargnier

The OpenClaw framework is emerging as a powerful but unstable tool for agentic software.

Developers are adding external "harnesses" to prevent agents from breaking their own configurations. New updates include GBrain, which uses Postgres-based queues to make subagents 10X faster. These tools focus on making agents reliable enough for production environments.

via Garry Tan, Harrison Chase

The models target biology, drug discovery, and medicine. The goal is to move from assisting research workflows to managing autonomous labs. This signals OpenAI's intent to capture value in high-stakes scientific industries.

via OpenAI

Market analysts warn that AI spending is increasingly driven by competitive fear.

Corporate boards are funding AI projects to avoid falling behind peers. There is a growing gap between investment levels and demonstrated financial returns. This trend suggests a potential market correction if boards begin demanding specific ROI metrics.

🔬 RESEARCH WORTH KNOWING

JAX proficiency has replaced PyTorch as the primary hiring signal for senior AI engineers.

PyTorch experience suggests a candidate can implement existing models. JAX experience indicates a candidate can optimize and build new architectures. This distinction helps founders identify engineers capable of deep architectural work.

via François Chollet

The GDPval-AA benchmark is facing criticism for using models to judge other models.

The benchmark uses Gemini 3.1 to evaluate the outputs of other systems. Critics argue this method provides no objective data on model performance. Founders should look for benchmarks that use human-verified or deterministic ground truths instead.

via Ethan Mollick
